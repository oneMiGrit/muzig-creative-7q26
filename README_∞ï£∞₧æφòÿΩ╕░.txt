Muzig AI 영상 3편 소개 랜딩페이지 (실습용)

1. index.html을 더블클릭하면 컴퓨터에서 먼저 확인할 수 있습니다.
2. 영상은 assets 폴더에 들어 있습니다. 폴더 구조를 변경하지 마세요.
3. GitHub에서 새 공개(Public) 저장소를 만듭니다.
4. index.html 파일과 assets 폴더 안 파일 6개를 저장소 최상위에 올립니다.
   (웹 업로드에서는 assets 폴더를 유지하세요. 폴더째 올리기가 어려우면 VS Code 또는 GitHub Desktop 사용)
5. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save
6. 발행 주소는 https://사용자이름.github.io/저장소이름/ 형식입니다.
7. 공개 주소에서 방문 카운터가 자동으로 표시됩니다. 로컬 파일에서는 '배포 후 표시'가 정상입니다.

주의
- 웹페이지 방문 횟수는 hits.sh 서비스가 제공하는 요청 횟수입니다. 순 방문자 수가 아닙니다.
- 영상은 GitHub 업로드 연습을 위해 화질/용량을 줄인 미리보기입니다.
- 업로드한 영상에 대한 권리 및 서비스 이용약관은 게시 전 별도로 확인하세요.
- GitHub Pages는 공개 사이트입니다. 개인 연락처 등 민감한 정보를 올리지 마세요.
